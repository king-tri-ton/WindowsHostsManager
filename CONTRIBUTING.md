# Вклад в WindowsHostsManager

Спасибо, что решили внести вклад в **WindowsHostsManager** — универсальную CLI-утилиту для управления файлом `hosts` как в **Windows**, так и в **Linux**.
Чтобы процесс был простым и понятным, следуйте этим рекомендациям.

---

## Начало работы

1. **Форкните репозиторий**
   Нажмите кнопку **“Fork”** в правом верхнем углу страницы проекта на GitHub.

2. **Клонируйте свой форк**

   ```bash
   git clone https://github.com/king-tri-ton/WindowsHostsManager.git
   cd WindowsHostsManager
   ```

3. **Настройте upstream (оригинальный репозиторий)**

   ```bash
   git remote add upstream https://github.com/king-tri-ton/WindowsHostsManager.git
   ```

---

## Внесение изменений

1. **Создайте новую ветку**

   ```bash
   git checkout -b feature/ваша-функция
   ```

2. **Внесите изменения**

   * Добавьте или исправьте код в соответствии с архитектурой проекта.
   * Убедитесь, что ваш код соответствует стандарту оформления (PEP 8).

3. **Протестируйте изменения**

   * Проверьте работу утилиты на **Windows** и **Linux**, если возможно.
   * Запустите базовые команды (`list`, `add`, `remove`, `backup`, `restore`) и убедитесь, что они работают корректно.

4. **Закоммитьте изменения**

   ```bash
   git add .
   git commit -m "Добавлено: новая функция для управления hosts"
   ```

5. **Отправьте изменения**

   ```bash
   git push origin feature/ваша-функция
   ```

6. **Создайте Pull Request**

   * На GitHub выберите **“Compare & pull request”**,
   * Опишите суть изменений и их назначение,
   * Отправьте Pull Request на проверку.

---

## Стандарты кодирования

* Используйте **PEP 8** для стиля кода.
* Пишите **осмысленные сообщения коммитов**.
* Проверяйте обработку ошибок и вывод сообщений в консоль.
* Все изменения должны быть обратно совместимы (не ломать текущий функционал).

---

## Тестирование

* Перед Pull Request убедитесь, что:

  * Программа устанавливается через `pip` или `pipx`.
  * Команда `whm` корректно доступна в консоли.
  * В Windows требуется запуск от администратора, в Linux — через `sudo` (если нужно).

---

## Сообщения об ошибках и предложения

* Ошибки и идеи улучшений публикуйте во вкладке **“Issues”**.
* Указывайте:

  * ОС и её версию,
  * Версию Python,
  * Версию WindowsHostsManager (например, `2.0.0`),
